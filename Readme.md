<h1>Projeto Poke API</h1>

<h2>Sobre</h2>
<p>Este projeto é uma Pokedex desenvolvida para fins educacionais, utilizando a PokeAPI para consultar dados sobre Pokémon. O objetivo é praticar habilidades em HTML, CSS e JavaScript</p>

<h2>Funcionalidades</h2>
<ul>
    <li><strong>Listagem de Pokémon</strong>: Mostra uma lista de Pokémon com suas informações básicas, como número, nome, tipo e habilidades.</li>
    <li><strong>Carregamento Progressivo</strong>: Carrega mais Pokémon conforme o usuário solicita, usando um botão de "Ver mais".</li>
    <li><strong>Detalhes do Pokémon</strong>: Exibe a foto do Pokémon, seus tipos e habilidades.</li>
</ul>

<h2>Estrutura do Projeto</h2>
<ul>
    <li><code>index.html</code>: Arquivo principal HTML que contém a estrutura da página.</li>
    <li><code>assests/css/global.css</code>: Estilos CSS globais para o projeto.</li>
    <li><code>assests/js/poke-api.js</code>: Funções para interação com a PokeAPI.</li>
    <li><code>assests/js/main.js</code>: Código JavaScript para manipulação do DOM e lógica de carregamento.</li>
</ul>
